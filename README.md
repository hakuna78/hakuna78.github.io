# hakuna78.github.io

Personal research site of Chaewoo Kim. Plain HTML + CSS, no build step.

## Deploy on GitHub Pages
1. Create a public repository named exactly `hakuna78.github.io`.
2. Upload everything in this folder (index.html, assets/, README.md) to the repository root.
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `(root)` → Save.
4. After about a minute the site is live at https://hakuna78.github.io

## Editing
- Text: edit `index.html` (sections: interests, research, projects, talks, news, cv).
- Colors and spacing: `assets/css/style.css` (variables at the top).
- CV: replace `assets/cv.pdf`.
- Slides: PDFs in `assets/slides/`; architecture images (full + `_t` thumbnail) in `assets/img/arch/`.
